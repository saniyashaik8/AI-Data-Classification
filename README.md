
# AI Project 2: Data Classification Using AI

## Project Description
This project demonstrates supervised machine learning by training a
classification model on the Iris flower dataset.

## Objectives
- Load and understand a dataset.
- Split data into training and testing sets.
- Train a classification algorithm.
- Evaluate model performance.
- Predict the category of a new example.

## Technologies Used
- Python
- Scikit-learn

## Algorithm
Decision Tree Classifier

## Dataset
The Iris dataset contains 150 samples, four numerical features,
and three flower categories.

## How to Run
1. Install Python.
2. Install the required library:
   `python -m pip install scikit-learn`
3. Run:
   `python classification.py`

## Evaluation
The program prints accuracy, a classification report,
and a confusion matrix.
